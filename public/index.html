Owl

Memory-safety risk scanner for C/C++ repositories

Point Owl at a GitHub repository. Claude reviews only the C/C++ source (docs and other text files are ignored) for memory-safety bugs — dangling references, use-after-free, out-of-bounds access, undefined behaviour, data races and classic unsafe C — and rates the risk of putting that code in your critical path.

Every scan is a full review by Claude, which reads the source like a security auditor. If Claude is unavailable, Owl falls back to a basic pattern scan and tells you.
