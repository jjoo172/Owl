Owl

Memory-safety risk scanner for C/C++ repositories

Point Owl at a GitHub repository. It reads only the C/C++ source (docs and other text files are ignored), flags memory-unsafe patterns — unbounded copies, format strings, manual lifetimes, integer-overflowing allocations and more — and rates the risk of putting that code in your critical path.

Try:

1Access check

Confirms the repository is public, the branch exists and its source can be downloaded — before any scanning starts.

    2Scan

    Starts once the access check passes.

    Pattern matching finds candidates, not confirmed bugs — treat findings as a review checklist.
